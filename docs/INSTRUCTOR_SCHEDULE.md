# อาจารย์ดูปฏิทินห้องแลป + ส่งคำขอจองคาบเอง

> สถานะ: **รอ Pete review** (2026-11-06) — ยังไม่มีโค้ด
> จะทำบน branch ใหม่ที่แตกจาก `feature/online-prelaunch` (#134) เป็น PR แยก (ต้อง merge #134 ก่อน)

## ที่มา
- ตอนนี้มีแค่ admin ที่สร้างคาบได้ (`/admin/scheduler`) อาจารย์ไม่มีปุ่มขอจอง
- backend มี API ของอาจารย์อยู่แล้ว แต่ยังไม่มีหน้าเว็บ:
  - `POST /v1/bookings`: ส่งคำขอ ได้สถานะ pending แล้ว admin กด Approve / Reject
  - `GET /v1/bookings/mine`: ดูคำขอของตัวเอง

## หน้าตา (หน้าวิชาของอาจารย์ `/instructor/courses/:id`)
- แถบหัวมี `Member` กับ `appearance` อยู่แล้ว → เพิ่ม **`Schedule`** ไว้ข้าง appearance
- กด Schedule → **ปฏิทินรายเดือน** หน้าตาเดียวกับของ admin (ใช้ `MonthCalendar` / `Sidebar` ซ้ำ)
  - **วิชานี้:** สีตามวิชาแบบของ admin กดดูรายละเอียดได้ (ดูอย่างเดียว อาจารย์แก้หรือลบคาบที่อนุมัติแล้วไม่ได้)
  - **วิชาอื่น:** แสดงเป็น **"ไม่ว่าง · LC-123"** สีเทา บอกแค่ห้องกับเวลา ไม่บอกชื่อวิชา เพื่อให้รู้ว่าห้องว่างเมื่อไหร่
  - **คำขอที่ยังรออนุมัติของวิชานี้:** แสดงเป็นกรอบเส้นประ ป้าย "Pending"
- ปุ่ม **+ Send new request** เปิดฟอร์มเดียวกับ Class Scheduler (`CreateEventModal` โหมด request)
  - Course ล็อกเป็นวิชานี้
  - มีช่อง Class type (On-site / Online), Lab, ห้องที่อยากได้, จำนวนเครื่อง, วันเวลา, ทุกสัปดาห์ถึง และหมายเหตุ
  - ปุ่มเป็น **Send request** แทน Approve
- รายการ **"คำขอของฉัน"** ใต้ปฏิทิน: pending / approved / rejected พร้อมเหตุผลถ้าโดนปฏิเสธ

## backend ที่ต้องเพิ่ม
| API | ใช้ทำอะไร | สิทธิ์ |
|---|---|---|
| `GET /v1/calendar?month=&courseId=` | คาบทั้งเดือนของทุกห้อง วิชาอื่นตัดชื่อวิชาออก (`mine: false`, title = "ไม่ว่าง") | อาจารย์ของวิชา + admin |
| `GET /v1/scheduler/options?courseId=` | ห้อง (จาก K3s) + lab ของวิชานี้ที่มี image แล้ว | อาจารย์ของวิชา + admin |
| `GET /v1/bookings/mine` (มีแล้ว) | เพิ่ม filter `courseId` | – |

`POST /v1/bookings` ใช้ของเดิม ซึ่งรองรับ `mode` online / onsite จาก #134 อยู่แล้ว

## แก้เพิ่มเรื่องที่เจอ (2026-11-06)
- ปุ่ม Approve / Send request ไม่ทำอะไรถ้าฟอร์มไม่ครบ (สีจางอย่างเดียว) → **ให้บอกว่าขาดช่องไหน** เช่น "เลือกห้องก่อน" หรือ "ใส่จำนวนเครื่อง"
- ถ้ารายชื่อห้องว่าง (K3s ไม่ตอบหรือ worker ปิด) → ให้แสดงข้อความเตือนในฟอร์ม
